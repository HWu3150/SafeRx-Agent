# Cardiovascular Skill

Use this skill when the router indicates dominant cardiovascular burden.

Core lens:
- acute coronary syndromes, ischemia, arrhythmia, heart failure, shock, severe hypertension, vascular disease
- anticoagulation or antiplatelet context
- cardiac procedures, valves, stents, bypass, pacing, telemetry-relevant instability

The skill should surface medication evidence that explains why cardiovascular drug classes would plausibly appear during the current admission.
