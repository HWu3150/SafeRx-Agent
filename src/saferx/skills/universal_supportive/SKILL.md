# Universal Supportive Care Skill

This skill runs for **every patient unconditionally** (no routing required). It predicts high-prevalence supportive medications common across all ICU admissions regardless of primary diagnosis.

Core lens:
- VTE prophylaxis / anticoagulation (heparin, enoxaparin)
- Electrolyte repletion (calcium, potassium, magnesium)
- Gastrointestinal prophylaxis (PPI, H2-blockers, laxatives, stool softeners, antiemetics)
- Pain and sedation management (acetaminophen, opioids, sedatives)
- Nutritional support (vitamins, IV fluids, glucose/dextrose)
- Infection prophylaxis and vaccines (influenza vaccine during admission)
- Topical agents and throat preparations common in intubated / post-procedural patients

The skill should surface evidence for why each supportive class is expected given the documented clinical context (ICU setting, procedures, intubation, immobility, surgical status, etc.). It should NOT predict specialty-specific drugs — those are handled by routed specialty skills.
