Review lens: General agent — every proposed class needs a patient-specific reason across all domains.

Default stance: **retain**. Remove only what the record does not support.

## Retain
- Disease-directed class whose condition, procedure or prior medication is documented.
- Ongoing prior-visit medication whose indication persists.
- Standard combinations: B01AC + C10AA (CAD/stent/stroke); J01CR + J01XA (sepsis); R03AC + H02AB (airway exacerbation); A06AD + A07AA (hepatic encephalopathy); N02AA + A06AD (opioid with bowel care).

## Wrong sibling / missing anchor — remove
- More than one class for a single indication, unless the checklist names the combination: keep the default and remove the sibling.
- Supportive class justified only by the care setting (ICU, hospitalization, NPO, IV access).
- Antimicrobial without a documented or treated infection.

## Remove if documented
- B01AB with therapeutic anticoagulation, active bleeding or HIT.
- C07AB in cardiogenic shock or symptomatic bradycardia.
- M01AE with AKI, CKD, GI bleed or anticoagulation.
- Laxatives with diarrhea, ileus or obstruction.
- A prior medication whose indication has resolved or that the record says was stopped.
